Connecting and Managing Connectionspsql -U username -d dbname — Connect to a specific database as a user.
psql -U postgres — Connect to the default Postgres database.
\q — Quit and exit the psql interface.
\c dbname — Connect/switch to a different database.

🔍 Viewing Database Structure (List Commands)
\l — List all databases.
\dt — List all tables in the current database.
\d tablename — Show the structure, columns, and data types of a specific table.
\du — List all users and their roles.
\df — List all functions.
\dn — List all schemas.
